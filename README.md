# ML-BASES

## Goal

ML-BASES means Machine Learning Bases.

This project is a personal refresher to rebuild and strengthen my Machine Learning fundamentals through hands-on projects.

The goal is to review the core concepts, algorithms, and techniques of ML, identify gaps in my knowledge, and rebuild a solid foundation for more advanced projects.

The main topics covered in this project are:

- The basics of data analysis:
  - Univariate analysis
  - Multivariate analysis
- Formulating and testing hypotheses: transforming observations into hypotheses
- Fundamental analysis
- Developing a machine learning model
- Data preprocessing
- Model validation
- Model evaluation
